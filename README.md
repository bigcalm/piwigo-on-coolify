# Piwigo on Coolify

A self-contained project to deploy [Piwigo](https://piwigo.org/) photo gallery on [Coolify](https://coolify.io/).

> This project was created using [opencode](https://opencode.ai).

## Overview

This deployment includes:

- **Piwigo** - Open-source photo gallery software (PHP 8.3)
- **MariaDB 11** - Database server
- **Nginx** - Reverse proxy and static file serving
- **Supervisor** - Process management for PHP-FPM and Nginx

All passwords and URLs are auto-generated by Coolify's magic environment variables. No manual configuration of secrets is required.

## Prerequisites

- A Coolify instance (v4.x)
- A domain name configured in Coolify (optional, for SSL)

## Quick Start

### Deploy on Coolify (one-click from public repo)

1. **Create a new resource**
   - From your Coolify dashboard, select your project
   - Click **+ New** to create a new resource

2. **Select Public Repository**
   - Choose **Public Repository** from the available resource types

3. **Choose your server**
   - Select the server where you want to deploy Piwigo

4. **Enter the repository URL**
   - Paste: `https://github.com/bigcalm/piwigo-on-coolify`
   - Click **Check Repository**

5. **Verify the Build Pack**
   - Coolify will auto-detect `coolify.json` and select **Docker Compose** as the build pack
   - No manual configuration needed — all passwords are auto-generated

6. **Deploy**
   - Click **Deploy**
   - Assign a domain to the `piwigo-nginx` service for SSL (optional, can be done after)

That's it. Coolify generates all database passwords automatically via magic environment variables.

### Local Development

For local development, you need to provide the environment variables that Coolify would normally generate:

1. Clone the repository:

   ```bash
   git clone https://github.com/bigcalm/piwigo-on-coolify.git
   cd piwigo-on-coolify
   ```

2. Create a `.env` file with the required variables:

   ```bash
   cat > .env << 'EOF'
   SERVICE_PASSWORD_MYSQLROOT=$(openssl rand -hex 32)
   SERVICE_PASSWORD_MYSQL=$(openssl rand -hex 32)
   SERVICE_USER_MYSQL=piwigo
   SERVICE_URL_PIWIGO-NGINX=http://localhost:8080
   TZ=UTC
   EOF
   ```

3. Start the services:

   ```bash
   docker compose up -d --build
   ```

## How It Works

### Coolify Magic Variables

This project uses Coolify's [magic environment variables](https://coolify.io/docs/knowledge-base/docker/compose#coolifys-magic-environment-variables) to eliminate manual configuration:

| Variable | Generated By | Purpose |
|----------|-------------|---------|
| `SERVICE_PASSWORD_MYSQLROOT` | Coolify | Auto-generated root password for MariaDB |
| `SERVICE_PASSWORD_MYSQL` | Coolify | Auto-generated password for the Piwigo database user |
| `SERVICE_USER_MYSQL` | Coolify | Auto-generated username for the Piwigo database user |
| `SERVICE_URL_PIWIGO-NGINX` | Coolify | Auto-generated URL with domain routing via Traefik |
| `TZ` | Default `UTC` | Timezone |

The `coolify.json` file tells Coolify to use the Docker Compose build pack automatically, so no manual build pack selection is needed.

### Service Architecture

```
piwigo-nginx (Traefik proxy) -> piwigo (PHP-FPM on 127.0.0.1:9000) -> piwigo-db (MariaDB on port 3306)
```

### Volumes

The following persistent volumes are created:

- `piwigo-db-data` - MariaDB database files
- `piwigo-gallery-data` - Uploaded photos and thumbnails
- `piwigo-local-data` - Local configuration and plugins
- `piwigo-upload-data` - Upload directory

## First Setup

After deployment, navigate to your Piwigo URL (assigned via Coolify's domain setting). Complete the Piwigo installation wizard using these database credentials:

- **Database host**: `piwigo-db`
- **Database port**: `3306`
- **Database name**: `piwigo`
- **Database user**: Auto-generated (visible in Coolify's environment variables tab)
- **Database password**: Auto-generated (visible in Coolify's environment variables tab)
- **Table prefix**: `piwigo_`

## Updating Piwigo

To update Piwigo to a newer version, modify the `PIWIGO_VERSION` in the `Dockerfile` and redeploy.
