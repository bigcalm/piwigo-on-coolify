# Piwigo on Coolify

A self-contained project to deploy [Piwigo](https://piwigo.org/) photo gallery on [Coolify](https://coolify.io/).

> This project was created using [opencode](https://opencode.ai).

## Overview

This deployment includes:

- **Piwigo** - Open-source photo gallery software (PHP 8.3)
- **MariaDB 11** - Database server
- **Nginx** - Reverse proxy and static file serving
- **Supervisor** - Process management for PHP-FPM and Nginx

All passwords and URLs are auto-generated by Coolify's magic environment variables. No manual configuration of secrets is required.

## Prerequisites

- A Coolify instance (v4.x)
- A domain name configured in Coolify (optional, for SSL)

## Quick Start

### Deploy on Coolify (from public GitHub repo)

1. **Create a new resource**
   - From your Coolify dashboard, select your project
   - Click **+ New** to create a new resource

2. **Select Public Repository**
   - Choose **Public Repository** from the available resource types

3. **Choose your server**
   - Select the server where you want to deploy Piwigo

4. **Enter the repository URL**
   - Paste: `https://github.com/bigcalm/coolify-app-piwigo`
   - Click **Check Repository**

5. **Select the Build Pack**
   - Coolify defaults to **Nixpacks** — change this to **Docker Compose**
   - **Base Directory**: `/`
   - **Docker Compose Location**: `docker-compose.yaml`
   - Click **Continue**

6. **Assign a domain to piwigo-nginx**
   - Before deploying, go to the `piwigo-nginx` service configuration
   - Under **Domains**, enter your domain (e.g., `https://piwigo.example.com`)
   - Coolify will configure Traefik to route traffic and provision SSL automatically
   - **Without a domain, the service is not accessible externally**

7. **Deploy**
   - All passwords are auto-generated by Coolify's magic variables — no manual configuration needed
   - Click **Deploy**

## First Deployment

**The first deployment can take several minutes.** The piwigo container must download Piwigo, build the image, wait for MariaDB health checks, and auto-install. Subsequent deployments are faster since images are cached.

Piwigo auto-installs on first boot — no manual setup wizard is needed. The database and admin account are created automatically.

### Logging In

The admin account is created automatically during first boot:

- **Username**: `admin` (configurable via `PIWIGO_ADMIN_USER`)
- **Password**: Find this in Coolify under the resource's **Environment Variables** section, listed as `SERVICE_PASSWORD_PIWIGO`
- Navigate to your assigned domain and log in with these credentials

## Local Development

For local development, you need to provide the environment variables that Coolify would normally generate:

1. Clone the repository:

   ```bash
   git clone https://github.com/bigcalm/coolify-app-piwigo.git
   cd coolify-app-piwigo
   ```

2. Create a `.env` file with the required variables:

   ```bash
   cat > .env << 'EOF'
   SERVICE_PASSWORD_MYSQLROOT=$(openssl rand -hex 32)
   SERVICE_PASSWORD_MYSQL=$(openssl rand -hex 32)
   SERVICE_USER_MYSQL=piwigo
   SERVICE_PASSWORD_PIWIGO=$(openssl rand -hex 16)
   SERVICE_URL_PIWIGO-NGINX=http://localhost:8080
   TZ=UTC
   EOF
   ```

   Note: the `$()` syntax above won't expand in a heredoc. Run `eval` or set actual values manually.

3. Start the services:

   ```bash
   docker compose up -d --build
   ```

4. Tear down and clean up:

   ```bash
   docker compose down -v
   rm .env
   ```

## How It Works

### Coolify Magic Variables

This project uses Coolify's [magic environment variables](https://coolify.io/docs/knowledge-base/docker/compose#coolifys-magic-environment-variables) to eliminate manual password configuration:

| Variable | Generated By | Purpose |
|----------|-------------|---------|
| `SERVICE_PASSWORD_MYSQLROOT` | Coolify | Auto-generated root password for MariaDB |
| `SERVICE_PASSWORD_MYSQL` | Coolify | Auto-generated password for the Piwigo database user |
| `SERVICE_USER_MYSQL` | Coolify | Auto-generated username for the Piwigo database user |
| `SERVICE_PASSWORD_PIWIGO` | Coolify | Auto-generated admin password for Piwigo |
| `SERVICE_URL_PIWIGO-NGINX` | Coolify | Auto-generated URL with domain routing via Traefik |
| `TZ` | Default `UTC` | Timezone |

No custom networks are defined in `docker-compose.yaml`. Coolify creates its own network automatically and connects Traefik to it. Defining custom networks causes intermittent 504 timeouts.

### Service Architecture

```
Client -> Coolify Traefik -> piwigo-nginx (reverse proxy) -> piwigo (Nginx + PHP-FPM) -> piwigo-db (MariaDB)
```

### Volumes

The following persistent volumes are created:

- `piwigo-db-data` - MariaDB database files
- `piwigo-gallery-data` - Uploaded photos and thumbnails
- `piwigo-local-data` - Local configuration and plugins
- `piwigo-upload-data` - Upload directory

## Updating Piwigo

To update Piwigo to a newer version, modify the `PIWIGO_VERSION` in the `Dockerfile` and redeploy.
